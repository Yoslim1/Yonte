# Yonte Roadmap — Legacy Entry Point

This file is retained only so old links and bookmarks continue to lead reviewers to the current project direction.

The previous roadmap became stale as Yonte's architecture was audited and several decisions changed (feature/data ownership, documentation cohesion, AI authorization, backup recovery, migration ordering, and module strategy).

## Current authoritative roadmap

Start here:

- `docs/YONTE_MASTER_PLAN.md` — product destination, accepted architecture direction, execution order, major decisions, and tracked hardening map.
- `docs/architecture/YONTE_CONSTITUTION.md` — non-negotiable architecture laws.
- `docs/architecture/decisions/README.md` — durable Architecture Decision Records.
- `docs/architecture/migration/MIGRATION_PHASES.md` — dependency gates for implementation.

Operational status belongs in current GitHub Issues, Pull Requests, and CI rather than this file.

Do not add new architecture/product decisions to this legacy file. Update the Master Plan and, when appropriate, the relevant ADR or focused doctrine instead.
